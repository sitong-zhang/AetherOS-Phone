AetherOS 电脑版

独立从零搭建的 x86_64 PC 操作系统 · 与手机版共享名称与图标，但代码完全独立
Linux 6.6.70 x86_64 DRM/KMS 合成桌面 无手机代码包袱

内核与引导

标准 x86_64 Linux 6.6.70 bzImage + QEMU virtio 根盘，1280×720 横屏桌面。

PID1 服务管理

aether-init 挂载文件系统、按依赖启动守护、回收僵尸进程并自动重启。

DRM 合成器

原子 KMS 提交驱动 virtio-gpu，键鼠/平板输入，IPC 提供 status/screenshot。

桌面与品牌

程序化重绘的 AetherOS logo（荧光绿 A + 亮蓝胶囊）居中，顶栏含时钟/CPU/内存。

验证：无头 QEMU 实跑通过 — 合成器 serving on 1280x720、服务 0 失败、截图导出像素复核（绿 A 4362px / 蓝胶囊 1331px / 白 443px）。 代码位于 /workspace/aether-pc（src/ 自有用户态、构建脚本、文档），与手机仓库 aether-linux 互不干扰。
