# Aether OS 手机版 · 验收对照（总纲第九章）

**依据**：《Aether OS 总规划书（手机操作系统）》——唯一总纲
**验收对象**：自包含 Android APK `dev.aether.vm`，内置 ARM64 Aether OS（`kernel.img` + `system.qcow2` + QEMU 引擎），安装 → 打开 → 点一次开机 → 直接进桌面
**取证方式**：`vm/host/run_v6.sh` 启动 QEMU TCG 全系统闭环，客机 `phonetest.sh` 逐帧导出到宿主 `out/run-v6/frames/`，串口 `serial.log` 记录状态 JSON 断言
**本轮闭环指标**：`aether-vm` 退出码 0；显示打开 1 次；看门狗心跳超时 0；合成器异常退出 0；`SELFTEST_DONE=1`；深浅两套取证帧合计 96 帧（含 P1 两段式三吸附点 `74-*`、控制中心二级面板 `75-*`、按压当帧 `76-*`、边缘右滑 `77-*`、应用共享元素转场 `78-*`）

> 状态口径：**已实现** = 真机可交互且有帧/状态断言；**部分实现** = 核心路径可跑但规格未逐条齐平；**未开始** = 未落地，不宣称可用。
> 本文件面向公众，逐项如实标注，不虚报、不以演示数据冒充真实功能。

## 六、P1 材质与动效体系（M1–M12 + 五曲线 + 令牌 + 全局按压）

> 本轮在 P0 结构纠偏基础上落地《UI 规划书 V3.0》第七章（材质）、第八章（动效）、第十章（两段式通知中心 / 控制中心二级面板）。全部以真机取证帧与状态断言闭环，不实称完成。

- **材质配方表 M1–M12**（`src/aether-material.c` 表驱动）：壁纸遮罩、卡片、状态栏、Dock、通知中心、控制中心、磁贴关/开、对话框、底部 sheet、Toast、灵动岛共 12 类，各自固定模糊半径 / 降采样 / 通道数 / 圆角 / 染色 alpha / 高光 / 阴影 / 边缘 / 可按压；720×1280 物理像素 + 纯 C CPU 渲染，模糊半径按软渲染像素预算实调，不对已验证布局整体 ×2。
- **同帧模糊预算**：每帧至多一次全屏 premium 模糊，浮层打开走 `aether_glass_blur_veil()` 快路径，避免 720×1280 逐像素重浮点计算阻塞 IPC 看门狗（P0 已修复的回归未复发）。
- **动效五曲线**：C-OUT / C-INOUT / C-BACK / C-ELASTIC / C-LINEAR 全部落地；时长阶梯统一取自 `aether-tokens.h` 的 `TK_D_*`（90/150/200/250/300/350/500/600ms），业务层不再写 `GLASS_*` 裸时长。
- **可打断续接**：转场统一为「视觉值 e」区间句柄，`aether_anim_begin_from()` 按剩余距离压缩时长、反向打断不跳回起点；弹簧 `aether_spring_*()` 二阶积分用于浮层吸附。
- **两段式通知中心**：240/640/全展开三吸附点 + 弹簧吸附，跟手拖拽与松手吸附共用一套可打断句柄；跟手侧滑清除。
- **控制中心二级面板**：3×3 磁贴长按展开二级面板（WiFi / 蓝牙 / 亮度等），从磁贴矩形连续展开。
- **全局按压反馈**：`down` 当帧即提亮 + 微膨胀（按压进度 `PRESS_IMMEDIATE=0.22`），经 `aether_material_set_touch()` 注入材质层，按钮 / 卡片 / 磁贴 / 灵动岛按钮统一接入。
- **图标共享元素转场 T-01/T-02**：应用从来源图标矩形放大展开、返回缩回来源矩形（视差），统一曲线时长，无闪黑/闪白。

## 七、工程自证（总纲 §9.7 / 第三章第 7 条）

- 独立新工程：`aether-vm`（Android 宿主，`dev.aether.vm`）与 `aether-pc`（Aether OS 客机用户态，纯 C 自研 init + 图形合成器），包名、目录结构、皮肤、代码组织均为自有。
- 客机为自研 Linux 用户态（内核 `Linux 6.6.70` ARM64 直引导），不是 Android、不是任何现成发行版；宿主引擎为 QEMU 8.2.0 源码交叉编译产物，未沿用第三方成品换皮。
- 所有第三方能力按「开源优先、先搜后用」纳入上游快照与许可证，见 `third_party/liquid-glass/`、`third_party/android-compat/` 的 `SOURCE.md` / `MAPPING.md` / `SHA256SUMS`。

## 八、诚实边界

- **安卓兼容层为能力探测 + 条件路径 + 诚实降级**，不是已跑通 pKVM 图形客机：AVF 的 `VirtualMachineManager` 是 API 34+ `@SystemApi`、需 `MANAGE_VIRTUAL_MACHINE`，且面向 headless / Microdroid 无图形 HAL，普通第三方 APK 实际生效路径恒为 QEMU TCG；LineageOS arm64 rootfs 未随包分发，**不宣称可在桌面运行百万安卓 APK**。
- 触感分级、系统音效、真实通话/录音硬件、动态壁纸、投屏等依赖客机硬件能力的项目，在 QEMU TCG 环境无对应设备，标注为未做，不以视觉占位冒充。
- 逐帧目视覆盖关键页面与上表所列帧，**未对每一帧逐一人工复核**；Android 物理设备上的 SDL 缩放、触摸映射、安装流程仍待真机验收。
