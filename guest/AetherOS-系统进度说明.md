## 一、本轮"做加法"的落点

总纲第二章规定既有基线（ARM64 / Linux 6.6.70 / qcow2 / 内核直引导 / 自研 init + 自研合成器 / QEMU 8.2.0）「只许做加法，不许推翻重来」。经核查，客机源码 `aether-pc/src/` 已是一台完整手机 OS 的骨架，但发布基线用 `-DAETHER_MINIMAL` 把桌面**阉割成只剩「设置」一个图标**。本轮因此**不重写架构，只解除阉割并在既有骨架上做加法**：

| 维度 | 之前（发布基线 1.0.11） | 本轮（系统 v2） |
|---|---|---|
| 桌面 | 仅「设置」一个图标 | 双页 4 应用磁贴 + 时钟/系统状态小组件 + 页面指示点 + 固定 Dock |
| 图标 | 纯色方块 + 首字母 | 超椭圆玻璃底 + **Lucide 开源线性符号**（76 个，ISC，一套描边体系） |
| 状态栏 | 纯文字「离线 100%」 | 单色线性图标（信号/Wi-Fi/蓝牙/电量）+ 真实电量读取 |
| 下拉 | 单一通知面板 | 左下拉通知中心 / 右下拉控制中心**分区**，3×3 磁贴开/关两态 |
| 主题 | 仅深色 | 深色 / 浅色**双主题完整可用**，控制中心一键实时切换 |
| 应用入口 | 桌面单图标 | 桌面 8 应用 + 全屏应用抽屉 |
| 手势 | 仅点击 | 点击 + 左右滑动换页 + 上下滑开/收抽屉与面板（真机触摸与 IPC 同源） |
| 开机 | 文字 logo + 直线进度 | 暗场 → 柔光 → 环形闭合 + 沿环光点游走 → 品牌字显影 → 细进度线（无旋转加载圈、无跳数字） |
| 中文字体 | 点阵字库覆盖不全，缺字显示问号 | 从 Noto Sans CJK SC（OFL）重生成 844 字点阵，界面文案全覆盖 |

**总纲「图标铁律」执行证据**：图标全部取自开源库 Lucide（`lucide-static v0.468.0`, ISC License），由 `tools/gen_icons.py` 离线光栅化为 alpha 掩膜编入 `src/aether-icons-data.h`；原始 SVG 留存于 `assets/`。生成物头部标注来源与许可。禁止手绘/自造/AI 生成/截图抠图 —— 全部满足；全系统同一套 24×24 / stroke-width 2 / round cap 描边体系。

## 二、验证（可运行、可复现，非演示数据）

两条独立路径均产出**真实帧**：

1. **x86 host 合成器（headless 逻辑画布）**：用 IPC 逐状态驱动，导出 11 张界面 PNG（`ui-shots/`），并用状态断言验证交互：
   - `click 96 190` → `state:2→3`（磁贴点击真实开窗），非兜底
   - `down→move→up` → `page:0→1`（滑动换页）
   - `panel/drawer/theme` 字段按预期切换
2. **ARM64 虚拟机客机（新系统盘 qcow2）**：把完整版合成器注入系统盘，用 QEMU 真实开机，导出 6 张客机帧（`guest-*.png`）与总览图 `guest-overview.png`。串口自检 `SELFTEST_DONE=1`，宿主闭环判定 **闭环跑通 ✅ / VMRC=0**，六项断言全绿：桌面态、真实点击开窗、控制中心 `panel:2`、浅色 `theme:1`、抽屉 `drawer:1`、无兜底。

客机桌面帧经目视确认为**新桌面（4 玻璃磁贴 + 时钟 + Dock）**，不再是「仅设置」单图标 —— 证明写好的系统真正进了系统盘、在虚拟机里开机呈现。

## 四、第五章体验规格与第八章禁止清单（诚实边界）

- **达标**：不闪白/不闪黑（开机暗场渐进）、图标统一超椭圆 + 单色线性符号、深色浅色两套完整可用、浮层四层不混淆（本轮改为不透明实色隔离下层）、点按立刻有反馈（状态即时刷新）。
- **部分达标**：开机动画有环形与光点但**无壁纸强模糊过渡**（实时模糊尚未实现）；解锁为点击/上滑即时切换，**无壁纸放大下沉与图标铺开动效**；通知中心为单段展示，**未做 5.9 的两段式下拉**；转场为即时切换，**无统一曲线动效**。
- **未做**：灵动岛三态与连续形变、控制中心二级面板、多任务卡片真实画面、小窗/分屏、实时毛玻璃（当前用不透明实色 + 圆角代替，未用静态图伪装，也未实现真算模糊）、矢量字体（当前为 16×16 点阵，放大保留点阵观感）、触感分级、系统音效。
- **第八章禁止清单**：本轮未引入白/黑闪屏、未用静态图假装毛玻璃、图标未混搭、未自绘图标、弹窗非凭空从正中弹出（覆盖层从顶栏下拉）、深色浅色两套均完整。**另**：本轮**未**做到"动效跟手/转场统一曲线"，属明确缺口，不掩饰。
