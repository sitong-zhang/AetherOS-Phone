## 二、为什么改

1. **交付形态与唯一需求源冲突**：仓库 README/ARCHITECTURE 仍把「自包含 APK 内嵌 QEMU」
   写成当前主线，而 v2 §1.3 / §13 明确禁止 APK、套壳、预览包。按「总纲优先」与
   §13 第 8 条（虚报状态），必须收敛口径并归档停用旧工程。
2. **v2 §2.1 要求动手前先跑基线、填实际数字**：v2 参考表是 2 核 / 3GB / 9.7GB / 非 root，
   本机实测 32 核 / 123GB / 154GB / root。照抄会误导「默认串行单实例」「帧率被硬限制」
   等结论；但「无 KVM → TCG 纯软件模拟」在本机同样成立，双轨必须保留。
3. **S2 核心是接口层**：v2 §5 明确「本阶段核心」，且 §5.6 要求把「自觉」换成脚本必过。
   历史 `guest/src` 有 13 个文件直连 `/dev/`、`/proc/`、`/sys/class/`，必须先有可替换的
   L2 抽象，才能逐轮把这些直连收敛下来（§2.7 一轮只改一类问题）。
