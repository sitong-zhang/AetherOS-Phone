## 0. 定位与口号

AetherOS = **基于 Linux 内核、用户态完全自研、主打安全的手机操作系统**。
目标是刷入开发板与谷歌 Pixel 真机实测；当前在云电脑上做系统调试与构建，软件模拟只是手段。
**不做 APK、不套壳、不交付预览包。**

> **口号：长明 Aether · 机可失，密不失**（副：灯不灭，密不泄）

安全主线：**手机丢了 / 被夺 / 被逼问 / 被插线拆解，也护住数据。**

## 1. 威胁模型（这套系统防谁）

| 攻击者 | 能力 | 防护档 |
|---|---|---|
| 捡到/偷到手机的人 | 猜解锁屏口令、连按错密码 | 常规档：输错达阈值抹除用户数据 |
| 胁迫机主的人 | 逼问出密码、要求当面解锁 | 胁迫档：诱饵环境、真实卷不挂载 |
| 有电脑的取证者 | USB 数据强插、ADB、刷机、读盘 | 熔断档：检测即连系统抹除、变砖 |
| 有工具的拆解者 | 拆机、短接测试点、物理提取 | 熔断档：防拆触点/短接 → 报警 + 删系统 |
| 离线爆破者 | 拿到磁盘镜像离线穷举 | 高强度口令 + 设备密钥绑定 + 零存储锚 |
| 篡改者 | 改审计链、改计数、改系统分区 | 设备密钥 HMAC 审计链 + 完整性自检 |

## 2. 三档数据保护（严格区分，不可混）

| 档 | 触发 | 抹除范围 | 后果 |
|---|---|---|---|
| **常规** | 锁屏口令输错达 `max_fails` | `data/` 用户数据 | `sys/` 系统本体逐字节保留，可再登录 |
| **胁迫** | 输胁迫口令(duress) | 不挂载真实卷 | 进诱饵环境、静默留痕 |
| **熔断** | 安全锁定态下 USB 强插/拆机/短接 | **`data/ + sys/ + journal/ + receipt/ + lockdown/` 全部** | **永久变砖，需外部重刷** |

> 常规档与熔断档的核心区别：`ae_secure_wipe()` 硬断言 `sys/` 逐字节不变；
> `ae_ld_brick()` 则连 `sys/` 一并抹除。二者共用同一隔离存储后端，绝不互相顶替。

## 4. 招牌安全功能

### 4.1 既有（`secure/`，96→179 自测坐实）
- 输错口令即自毁保险库、**离线可验销毁证明**
- **胁迫口令 → 诱饵环境**（可做深：蜜罐诱饵文件）
- **一键熔断 Panic**、防篡改审计链、系统完整性自检（篡改即擦）
- **TEE 密钥锚点**（软件当前 / 硬件真机）、**设备自证 Attestation**
- 会话空闲锁定、暴力破解指数退避、内存密钥清零(mlock+zero)

### 4.2 新增：安全锁定 / 熔断模式（Lockdown Mode，本轮实现）

**首启硬门（OOBE 前置步骤，不设定无法进入系统）**
- 引导链：`语言 → 时区 → 网络(可跳过) → 隐私协议 → 设定专用安全密码(不可跳过) → 完成 → 锁屏`
- 硬门挂在 L3 init 服务编排之前，配合验证启动，防止进 recovery / 刷 system 绕过。
- `ae_ld_oobe_gate()`：未设定或已变砖 → 不放行进系统。

**专用安全密码规格**
| 项 | 规格 |
|---|---|
| 长度 | 20–30 位 |
| 字符类 | 必含大写 + 小写 + 特殊符号 |
| 连续序列 | 递增/递减连续序列(123…/abc…)长度 ≤ 5（12345 允许、123456 拒绝） |
| 性质 | 不可重置、不可找回、无修改入口、**仅首次设定有效** |
| 确认交互 | 确定后弹二次确认窗：警告「务必物理抄录」+ **明文再回显一遍密码** + **确定按钮 10 秒冷却** |
| 存储 | **系统零存储密码明文**：密码即 wrapping key，落盘的只有 `verifier = HMAC(device_key, PBKDF2(pw, salt))`，由密码单向派生、无法倒推；密码明文不落盘/不进日志/不进快照，用完即从内存清零 |

> 「零存储」精确语义：要判断密码对错，系统必须留一个**由密码参与、无法倒推回密码**的
> 验证锚；若连锚都不留，则连机主自己都永远无法解锁。故留的是「锚」不是「密码」。
> 真机把 `device_key` 放进 TEE/eFuse 后，离线爆破该锚也不可行；云端为软件锚点，如实标注。

**进入安全锁定模式（组合键手势）**
1. `电源键 + 音量下` **同时按住满 10 秒**：不足 10 秒无效；超时保持「待确认」不自动进入；
2. 满 10 秒后**再按一下音量上** → 进入安全锁定模式；
3. **未设定专用密码时组合键完全无效**（防误触、防他人乱按弄砖）。

**进入后（三条红线）**
- **唯一解锁 = 专用安全密码**；其余路径全封死：锁屏/生物/ADB/recovery/刷机/USB/调试口。
- **USB 数据强插 → 一旦监测到立刻抹除所有数据（含系统本体）并变砖**。
- **物理拆机 / 测试点短接 → 触发报警机制 + 删除系统**。
- 忘记密码 = 永久锁死，无找回、无后门、无救援口令；`BRICKED` 状态跨重启持久。

### 4.3 物理接口层（先做接口，真机以后适配）
`aether_hal`：把 USB 数据接入、机壳防拆触点、测试点短接、组合键(电源/音量)、
蜂鸣器报警、安全芯片在线状态、单调时钟 抽象成**可替换接口**。
- 云端：`AE_HAL_SIM` 故障注入仿真 + 可注入时钟（确定性测试）；
- 真机 S6：`AE_HAL_HW` 换 GPIO + Titan M/eFuse，上层零改动（V2 §3.3 / §5）；
- 当前 `AE_HAL_HW` 为**占位未实现**，`open` 如实返回失败，绝不伪造硬件能力。

## 5. 逐条验收口径（机器可判）

| 能力 | 验收 | 现状 |
|---|---|---|
| 密码强度 | 20/30 边界、缺每类字符、连续序列 5/6 边界各一用例 | ✅ 组 L1 |
| 首启硬门 | 未设定 `oobe_gate=0` 且组合键无效 | ✅ 组 L2 |
| 10 秒冷却 | `<10000ms` 拒绝、`≥10000ms` 通过、未满不落锚 | ✅ 组 L2 |
| 零存储 | 全盘扫描运行根，密码明文 0 命中；验证锚存在 | ✅ 组 L2 + CLI 取证 |
| 不可重置 | 二次 `provision_begin` 拒绝 | ✅ 组 L2 |
| 组合键 | 不足10秒/松开/超时不进；满10秒+音量上才进 | ✅ 组 L3 |
| 仅密码可解 | 错误密码无旁路、正确密码退出、状态跨重启持久 | ✅ 组 L3 |
| 物理熔断 | USB/拆机/短接 三种事件 → 报警 + 连系统抹除 + 变砖 | ✅ 组 L4 |
| 变砖终态 | 任何密码/事件都退不出、开机硬门永久拦截、`sys/` 保持空 | ✅ 组 L4 + CLI 引导级拦截 |
| 三档分离 | NORMAL 态 USB 事件不误触发熔断 | ✅ 组 L5 |
| 密码学 | OpenSSL 3.x 独立复算标准向量 | ✅ 4/4 |

**当前自测：`bash scripts/secure.sh test` → 179 PASS / 0 FAIL + OpenSSL 交叉验证 4/4。**

## 6. 诚实边界（不实称完成）

1. 标「已实现」的是 `secure/` 里**用户态安全整机**（x86_64 本机 CLI 程序），
   通过了 179 项自测；但它**不是随 Linux 手机 OS 启动的服务**，离「随系统出货」还有集成工作。
2. 物理事件检测在云电脑是**故障注入仿真**，不是真的 USB 电气检测 / 拆机检测；
   「任何方式都破解不了」要真正成立，依赖真机 **TEE / 安全芯片 / eFuse**，属 S6 阶段。
3. H1–H4（验证启动 / 故障隔离 / 地址隔离 / 内核硬化）属 Linux 内核与引导层，
   当前为**未开始**，不在本轮用户态安全整机范围内。
4. 熔断删除的是**模拟整机磁盘目录**里的文件；真机「变砖」由 bootloader/安全芯片管控，
   云端以「抹除系统区文件 + 落 `BRICKED` 墓碑 + 引导级拦截」仿真，如实标注。
5. 二次确认弹窗在云端 CLI 以文本 + 可注入时钟呈现；真实 GUI 弹窗/10 秒冷却按钮
   属 B 轨交互层，待桌面接入。
6. `kernel/`（自研 x86_64 R&D）经漏洞清单 V1–V17 审计有缺陷，**非产品内核、不代表产品安全**。

## 7. 复现命令

```bash
bash scripts/secure.sh build          # gcc -Werror 编译
bash scripts/secure.sh test           # 179 PASS / 0 FAIL + OpenSSL 4/4

# CLI 端到端（独立运行根，确定性时钟）
BIN=build/bin/aether-os; R=/tmp/aether_ld_demo; PW='Abc!Def@Ghi#Jkl$Mn0PqRs'; rm -rf $R
$BIN --root $R --no-delay --ld-now 1000  ld-provision --pw "$PW" --now 11000  # 首启设定
$BIN --root $R --no-delay               ld-status                              # 硬门已放行
$BIN --root $R --no-delay --ld-now 40000 ld-gesture --now 40000               # 进入安全锁定
$BIN --root $R --no-delay               ld-unlock --pw "$PW"                   # 仅此密码可退
$BIN --root $R --no-delay --ld-now 70000 ld-inject usb --now 70000            # 物理红线 → 变砖
grep -rlF "$PW" $R || echo "零存储：运行根内无密码明文"
```
