# round-004 证据清单 · 安全锁定 / 熔断模式

- 范围：按 V2 总纲「主打安全」新增的**安全锁定 / 熔断模式**（用户态安全整机 `secure/`）。
- 环境：云电脑用户态 CLI（软件仿真）；物理事件走 `aether_hal` 故障注入，非真机电气检测。
- 复现：`bash scripts/secure.sh build && bash scripts/secure.sh test`；CLI 流程见 `SECURITY-BASELINE.md` §7。

**关键结论（外部可观测）**
1. 密码明文零落盘：全盘扫描运行根 0 命中；落盘的是无法倒推的验证锚。
2. 首启硬门 / 10 秒冷却 / 组合键满 10 秒 + 二次确认 / 仅密码可解锁 均由状态机强制。
3. USB 强插 / 拆机 / 短接 → 报警 + 连 `sys/` 一并抹除 + 永久变砖；变砖跨重启持久，引导级拦截。
4. 三档语义分离：常规档保留系统、熔断档删系统；NORMAL 态物理事件不误触发。

**诚实边界**：物理检测为云端仿真；「任何方式破解不了」在真机依赖 TEE/安全芯片/eFuse（S6）。
H1–H4（验证启动/故障隔离/地址隔离/内核硬化）属 Linux 内核层，当前未开始。
