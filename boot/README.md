# 整机引导链路规格

本文件定义 AetherOS 的整机引导链路（A 轨）：在云计算机上以 QEMU TCG 软件模拟，从
Linux 内核引导到自研用户态输出首帧，并逐环留存证据。整机链路用于验证「引导 → 内核 →
挂载根文件系统 → init → 服务编排 → 图形首帧 → 输入生效」是否连通。

## 链路组成

| 环节 | 内容 |
| --- | --- |
| 内核 | Linux 6.6.70（ARM64），从源码构建或使用带校验和的预编译镜像 |
| 根文件系统 | 自建 ext4 根盘：BusyBox 基座 + `guest/src` 交叉编译产物 + init 服务清单 + 开机自检 |
| PID 1 | 自研 `aether-init`，负责挂载与服务编排 |
| 服务 | aetherosd、合成器、看门狗、开机诊断、自检 |
| 显示 | virtio-gpu 输出首帧 |
| 验证 | 串口日志、逐帧导出、输入注入改变画面、开机门禁机检 |

外部资产（内核源码、内核配置、BusyBox 基座、字体）以 SHA-256 校验清单管理；获取脚本先校验
本地缓存，缺失时从上游下载。所有路径由脚本自身位置推导或经环境变量注入，构建产物落在
`build/`。

## 与上层代码的关系

用户态源码统一取自 `guest/src`：调试环境的原生构建、整机链路的 aarch64 交叉编译、真机移植
使用同一份源码，仅构建目标与硬件接口层实现不同。接口层定义见 `l2/include/`。

## 构建与运行入口

```bash
# 环境基线
python3 tools/collect_baseline.py

# 六种一键操作（统一入口）
bash scripts/aether.sh build       # 构建
bash scripts/aether.sh start --track A   # 整机链路
bash scripts/aether.sh test        # 自测 + 静态机检
bash scripts/aether.sh evidence    # 导出证据

# 用户态交叉编译（guest/ 内已有脚本）
bash guest/build-aarch64.sh
```

`scripts/aether.sh` 的 A 轨前置检查会核对内核镜像与根文件系统是否齐备，缺失时明确报出所缺
资产，不模拟启动成功。

## 当前状态

整机引导链路当前处于建设阶段，尚未产出「冷启动到首帧 + 逐帧取证」的闭环证据。

## 工程边界

- 整机链路只证明链路连通，不用于帧率、动效手感与长稳验收；交互与像素验证由原生上层轨道承担。
- 触摸、音频、相机、基带、TEE/eFuse 与刷真机属于真机阶段，调试环境使用 QEMU virtio 仿真设备。
- 软键盘（含中文输入）是整机闭环的一票否决验收项，属后续阶段，当前未计入已通过。
- 若使用带校验和的预编译内核镜像开机，证据中会明确记录「未现场重编内核，源码、配置与构建
  脚本齐备可复现」。
